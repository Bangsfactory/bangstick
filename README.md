# Bangstick

**생각을 실행하는 작업공간.**  
앱을 만들고, AI와 함께 일하세요.

[공식 홈페이지](https://bangstick.space) · [Windows 다운로드 / Releases](https://github.com/Bangsfactory/bangstick/releases)

## 하나의 작업공간에서

- **작업공간** — 파일과 앱을 한곳에서 열고 관리합니다.
- **AppHub** — 필요한 앱을 찾아 설치하고 실행합니다.
- **앱 제작** — 아이디어를 직접 만들고 실행해 봅니다.
- **AI 채팅** — AI와 대화하며 앱과 작업을 연결합니다.

## 다운로드

Windows 설치 파일은 이 저장소의 [Releases](https://github.com/Bangsfactory/bangstick/releases)에서 배포합니다.

현재 설치 파일은 배포 준비 중입니다. 릴리스가 게시되면 버전별 설치 파일과 변경 사항을 확인할 수 있습니다.

## 이 저장소의 역할

Bangstick의 제품 소개, 설치 파일 및 업데이트 안내를 위한 공식 저장소입니다. 앱 소스 코드와 계정·서버 운영 데이터는 포함하지 않습니다.
